# Write and commit tests first
1. Write tests based on expected input/output pairs.
2. Run the tests and confirm they fail. Do not write any implementation code at this stage is often helpful
3. Commit tests only when I am satisfied

# Write code, iterate, commit
1.  Write code that passes the tests, you will NOT modify the tests. 
2.  Continue making changes till all tests pass.
3.  Don't overfit the implementation to tests
4.  Commit the code when I am satisfied
